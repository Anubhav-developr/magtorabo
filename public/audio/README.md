# Google AI Studio voice files

Generate Hindi TTS files and place them in this folder with these exact names:

- `welcome.wav` — startup welcome
- `calendar.wav` — calendar explanation
- `complaint.wav` — complaint book explanation
- `links.wav` — useful links explanation
- `village.wav` — village/map selection explanation
- `magtora.wav` — Magtora-specific explanation

The app plays each guide once per page session when that section is first opened.
